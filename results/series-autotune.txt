Выводы:
- TU_AUTOTUNE_ALGO=profiled ничего не даёт — тайлинг-решения базового
  алгоритма уже правильные для этой игры.
- TU_AUTOTUNE_FLAGS=big_gmem стабильно хуже на 1.5 кадра (почти на 12%):
  увеличивать занятый GMEM на проход здесь вредно. Антирекомендация.
- TU_MAX_DRAW_STATES=64 сам по себе no-op: в дереве проп читается только
  в tu_autotune.cc:339 как гейт mod_flag::PREEMPT_OPTIMIZE, а порог
  TU_DRAW_STATE_AT_WRITE_RP_HASH = TU_DRAW_STATE_COUNT+1 = 33. При
  дефолтных 32 условие ложно, при 64 истинно — то есть 64 включает только
  доступность флага preempt_optimize (значение из шаблона a7xx_gen3,
  freedreno_devices.py:901; a740 наследует 32 от a6xx_base:152).
- Комбо mds64 + preempt_optimize даёт 0 — preempt-оптимизация кадр не
  двигает.
- load_inline_uniforms_via_preamble_ldgk даёт 0 при байт-в-байт
  корректности теста.
- load_shader_consts_via_preamble не замерялся: порча воспроизведена
  (все чтения 0x00000000, см. раздел 14.3).

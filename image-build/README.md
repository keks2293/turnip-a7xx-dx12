# Сборка образа: как патчи 0001–0003 попадают в RPM

Справочная копия recipe сборки пакета mesa для образа ArmadOS — здесь ничего
не запускается, файлы лежат рядом, чтобы этот репозиторий был самодостаточным:

- `BASE.env` — пин версии Mesa (26.2.3) и SHA256 тарболла;
- `build.sh` — как патчи `patches/0001–0003` подставляются в RPM spec
  (`Patch9001–9003`) при сборке образа;
- происхождение каждого патча и внешние источники — `../patches/PATCHES.md`.

Патчи ship-ятся в `patches/`; 0004–0011 к RPM-recipe отношения не имеют —
они применяются к дереву исходников (`scripts/build-turnip.sh`).
